# Owner policy record (handoff §23 "needed before production")

Decisions taken by the owner, 2026-11-14 (this session). Each entry notes
where it is implemented. Unaffected §23 items (launch content, off-machine
backup destination, monitoring/rollback/drain procedures, measured

## Decided

| §23 item | Decision | Implemented |
| --- | --- | --- |
| Admin recovery | CLI grant command; no web path. `manage.py grant_admin <discord_id>` on the controller restores admin (creates the account pre-approved if the old Discord identity is gone; reinstates a suspended one). | `accounts/management/commands/grant_admin.py` |
| Account rejection / deletion / anonymization | **Reject only.** Rejected accounts reapply by logging in again (2026-11-14 decision). Nothing is ever deleted or anonymized — scores and audit history are permanent. | Existing reject flow (`adminops.reject_user`); no deletion path exists by design |
| Retention (audit/submissions/notifications) | **Keep everything indefinitely.** No expiry jobs exist or will be added; scores must never be lost (handoff §19). | No-op by design; recorded here |
| Alert destination + response process | **On-platform notifications to admins** (in-app inbox, not a webhook). Backup failures notify admins automatically; response process: check the notification, then `backups/backup.log` / `systemctl status` on the controller. | `submissions/management/commands/notify_admins.py`; wired into `backup/backup.sh` failure trap |
| Hint refund/deletion semantics | Refund removes ownership and returns the current price; redeemed hints are never deletable; unredeemed hints may be deleted. | `adminops.py` (owner decision 2026-11-14, already implemented) |
| Content withdrawal (archive mid-event) | **Scores retained.** Archived challenges vanish from browsing but all existing solves, scores, and hint ownership stay. | Existing archive semantics (`Challenge.Lifecycle.ARCHIVED`) |
| Backup frequency/retention/restore | Daily, 14-day retention, local-only destination, tested restore drill. | `backup/BACKUPS.md` (owner policy recorded there) |
| Secret generation | Generated by `server-setup.sh` at `.env` bootstrap; never auto-rotated. | `server-setup.sh` |
